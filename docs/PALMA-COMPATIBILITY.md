# BOOX Palma 오프라인 호환성 기록

## 사용자 실기기 관찰

- 기록일: 2026-08-20 KST
- 조건: 같은 단일 HTML 파일을 오프라인 상태에서 실행
- 정확한 Palma 세대·펌웨어·앱 버전: 미기록

| 실행 앱 | 결과 |
| --- | --- |
| HTML 뷰어 | JavaScript 계산 기능 동작하지 않음 |
| NeoReader | JavaScript 계산 기능 동작하지 않음 |
| NeoBrowser | 오프라인 동작 확인 |
| Chrome | 오프라인 동작 확인 |

이 결과는 사용자 관찰이며 동일 기기에서 독립 재현한 시험이 아닙니다. NeoBrowser와 Chrome에서 동작했다는 사실은 그 실행 경로가 네트워크 응답을 필요로 하지 않았다는 뜻이지, 기기·브라우저·운영체제의 안전이나 물리적 네트워크 격리를 증명하지 않습니다.

Palma에서는 파일을 길게 눌러 **다른 앱으로 열기 → NeoBrowser**를 현재 기본 실행 경로로 안내합니다.
